# Before you publish

Tick each box, in the release or PR description if it is public.

- [ ] `git ls-files` and the built artefact contain **no** Mojang jars, textures, sounds, models, fonts or lang files
- [ ] The Play page / site build was searched for Mojang assets (see ASSETS.md) and the result is recorded
- [ ] The disclaimer from NOTICES.md is in the README, on the site footer and on the Play page
- [ ] No Minecraft logo or wordmark is used as branding
- [ ] Every mod ported from another project has its upstream, author and licence recorded
- [ ] Every third-party icon or image has its credit and source link
- [ ] The DMCA policy is on the site and names a working contact address
- [ ] (US) A DMCA designated agent is registered with the US Copyright Office and the details on the site match
- [ ] Nothing in the release loads code or assets from another site that we don't control or have a right to use
- [ ] A lawyer has read the policy since the last big change
