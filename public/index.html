    Native mods for Horizon

    Your favourite mods, rewritten in Rust.

    Horizon is a rewrite of Minecraft: Java in Rust, and its mods are not plugins: they are source that gets merged into the game and compiled with it. This is a library of them. 9 are done, each one a tiny project with its own tests, its own release and a file you can read in five minutes.

    A mod is part of the game, not a guest in it

    Fabric loads Java into a running JVM. Horizon has no JVM. A native mod is Rust that horizon-mixins merges into Horizon's source before the compiler sees it, and the launcher builds a game for your instance with the mods already inside.

    1. HookHorizon keeps a short list of stable hook points: empty functions the game calls every frame, tick, key press, HUD draw.
    2. MergeA horizon-mixin.toml says which hook runs which helper, and adds the mod's runtime.rs to the game as a module.
    3. BuildThe launcher compiles the modded source for your instance. First build 20 to 30 minutes, later ones faster.
    4. PlaySwitch the mod on or off in Options, Mods. It has a settings page and, if it needs one, a key.

    The 9 mods

    Each folder in mods/ is a complete project: logic, tests, pins, licence, a release workflow. They are ports, written from how the originals behave and not from their code.

    FPS Display

    Frames per second in a corner of the screen, coloured by how smooth they are.

    fps_display 1.0.0 · 4 tests

    Sprint Indicator

    Shows Sprinting, Walking or Sneaking in a corner of the screen while you move.

    sprint_indicator 1.0.0 · 4 tests

    Key Overlay

    Shows W, A, S, D, jump and the mouse buttons on screen and lights the ones you hold.

    key_overlay 1.0.0 · 5 tests

    CPS Counter

    Your clicks per second in a corner of the screen.

    cps_counter 1.0.0 · 3 tests

    Info HUD

    Your speed, the way you face and your dimension in a corner of the screen, in the spirit of MiniHUD's info lines.

    info_hud 1.0.0 · 6 tests

    Custom HUD

    One box with the lines you pick: FPS, coordinates, facing and clicks per second, on the side you choose.

    custom_hud 1.0.0 · 4 tests

    Zoomify

    Hold a key to zoom in, turn the wheel to zoom further, with smooth easing and slower turning.

    zoomify 1.0.0 · 7 tests

    Simple Zoom

    Press a key to zoom in and press it again to zoom out; the wheel changes the zoom meanwhile.

    simple_zoom 1.0.0 · 7 tests

    Waypoints

    Name places with /wp, list them, and track one: its distance and direction show on screen.

    waypoints 1.0.0 · 8 tests

    What we do not pretend

    44 of the 186 catalogued mods are wanted but cannot be written yet, because the hook points do not give a mod an inventory, effects, incoming chat or the camera. Nothing here is marked ported unless a project builds, passes its tests and type-checks against a real Horizon.

    What Horizon needs to exposeHow it is kept honest
    Verified today: all 9 mods apply on Horizon ba6344a with horizon-mixins d9c83d7 and the game type-checks with warnings denied. They are unit-tested, formatted and clippy-clean. They have not been played in a live game by this project's CI, which cannot run a GPU build.
