    How a hook point gets added

    It is a change to Horizon, not to a mod: an empty function the game calls at a fixed place, a bump of NATIVE_HOOKS_API, and an entry in native-hooks.json. The most useful contribution this library can make is a pull request to horizon-rust/horizon that adds one, with a mod here that uses it.
