    Play Horizon in your browser.

    The offline build of Horizon: the game code is inside one HTML file, you point it at the folder that holds your game resources, and it runs. Nothing is downloaded while you play.

    Horizon (offline)

    A single HTML file, 8.0 MB. It contains the game and its loader; the resources come from your own folder.

    horizon-offline.html · SHA-256 924a531175b253406ab561a9167e9dc80f4e9080f3072b75faef2352906681a6

    How it starts

    1. Open the fileIt asks for a folder of game resources: the one that contains boot.tar.gz, manifest.txt and the res folder.
    2. Select itYour browser may ask you to confirm an upload; per the page, nothing leaves your computer. The resources are saved in this browser the first time, so you pick the folder once.
    3. Choose what to keepYou pick what is saved in the browser (sounds are optional; only UK English is kept). Game saves are kept in the browser too.

    What it needs

    WebGPU. The file says so itself when it cannot find one. It runs in Chrome and Edge 113 or later on Windows, macOS and ChromeOS; Chrome 121 or later on Android; Safari 26 on macOS, iOS and iPadOS; and Firefox 141 or later on Windows. On Linux, Chrome, Edge and Brave need WebGPU switched on with --enable-unsafe-webgpu --enable-features=Vulkan.

    What to know

    You bring the resources. The file contains none of Minecraft's resources: the game reads the folder you select, which you prepare from your own copy of Minecraft. No mods built in. The mods in this library are compiled into a game by Horizon's launcher (install guide); this single file is a separate build, so do not expect them in it. Unofficial.
