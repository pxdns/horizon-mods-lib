    Why native

    Mods you can read, test and trust.

    A plugin system is a promise that code you did not read will behave. Horizon's native mods make a smaller promise and keep it: the bundle is source, and the source is short.

    There is nothing to load

    A Fabric mod is a jar the game opens at start-up, patches with bytecode tricks and runs inside the same JVM. Horizon is native Rust, so a mod cannot be loaded that way, and does not need to be. horizon-mixins works on the game's source tree: it parses the Rust, applies the injections a mod declares, and the compiler sees one program. A hook is a function call that was written into the game before it was built. No reflection, no class loader, nothing that decides at run time what runs.

    The bundle is the source

    A .hnmod is a zip of .rs and .toml files and a licence. Nothing compiled is in it. The launcher checks it without running anything, refuses links, odd paths and anything beyond the bundle layout, and then builds it for your instance behind a red warning, because native code has the player's rights. Horizon's registry lists a native mod only after a maintainer has read its source. You can do the same in the time it takes to drink a coffee: here, a mod's logic is one file of a few hundred lines at most.

    Logic that does not need the game to test

    Each project's Cargo library is its runtime.rs. The game's types never appear in it; the hook helpers read what they need and pass plain values in. That is why a zoom's wheel limits, a waypoint's bearing maths and a speedometer's smoothing have unit tests that run in under a second, and why a bug in them is a failed test instead of a crashed game.

    Small on purpose

    There are no dependencies in any of these projects. There is no unsafe, no network access and no process spawning. A mod that is switched off in Options does nothing at all until the next build leaves it out. Settings are one file per key in the mod's own folder.

    What it costs

    Build time. Every set of mods is a build of the game: the first one downloads a toolchain and takes 20 to 30 minutes, a rebuild of one changed helper takes a few minutes. Reach. A native mod can only do what a hook point allows. Servers. Native mods are not built for dedicated servers yet; on a server you join, only client-side hooks do anything. Maturity. Native mods are experimental in Horizon. We say so on every page that matters.
