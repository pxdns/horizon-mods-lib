    Mod catalogue

    Every mod in the Tempest project's cross-pack matrix (docs/MOD-MATRIX.md in pxdns/patcher): 186 mods, 35 ported · 18 partly ported · 8 built into horizon · 30 pack or asset · 32 engine or server · 28 library · 35 no 26.3 build.

    Horizon implements Minecraft 26.3, so the 26.3 column decides what can be ported at all. A native Horizon mod can only use what Horizon's native hook points expose (frame, tick, HUD, key, wheel, command, zoom, minimap, mods list, settings and the world lifecycle, plus the item panel and recipes), which is why most Fabric mods that rewrite rendering, networking or inventories wait for more hook points. The status below says which case each mod is in; nothing is marked ported unless a project in mods/ builds and passes its tests.

    Status

    Status Meaning
    Ported A project in mods/ implements it for Horizon, independently of the upstream code
    Partly ported Only the part the hook points allow is in a project
    Built into Horizon Horizon ships it as one of its own extras
    Needs a hook point Wanted, but Horizon does not expose what it needs yet
    Pack or asset Belongs in the registry as a resource, shader or data pack
    Engine or server Performance or server work that Horizon's own engine replaces
    Library A helper other Fabric mods load; native mods do not use it
    No 26.3 build The upstream mod has no build for Horizon's game version

    Upstream licences are copied from each project's Modrinth page. They are listed for credit and to show that this repository copies no upstream code or art: every port is a clean re-implementation of the behaviour.
