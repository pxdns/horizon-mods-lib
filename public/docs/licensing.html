    Code

    Everything in this repository (the mods, the tools, the site, the documentation) is MIT, see LICENSE: Copyright (c) 2026 pxdns and the horizon-mods-lib contributors. Each project folder carries its own copy, and the .hnmod includes it as mixins/<id>/LICENSE, so the notice travels with the sources.

    Upstream mods and clean-room ports

    The ports are written from behaviour, not from upstream source. Nobody here has copied or translated another mod's code, art, text, or data files; the reference was what the mod does when you use it, and its public description. Several upstream mods are LGPL, GPL or all-rights-reserved; none of that applies to a program that contains none of their code. A port can still share a name or idea with its original, and the credits say whose idea it was.

    If you contribute a port: do not paste upstream code into a pull request, and do not translate it line by line. Describe the behaviour, write the Rust, test it.
