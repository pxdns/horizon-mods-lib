    Tempest's modules

    The Tempest client (pxdns/patcher) groups its features into modules. This is the full list from the 26.2 module docs and the 1.16.5 port table, with where each one stands on Horizon. The 1.16.5 browser port keeps three modules working (Fullbright, InvMove, No Death Animation) plus the item-scale, Clean F3 and hit-crosshair hooks; see docs/1.16.5/PORT-STATUS.md.

    The Horizon organisation

    github.com/horizon-rust holds eight public repositories:

    Repository What it is
    horizon The game, launcher, server and tools: a rewrite of Minecraft Java 26.3 in Rust (MIT)
    horizon-mods The registry of reviewed mods, modpacks and resource and shader packs the launcher lists; also Horizon's own native mods
    horizon-site The website at playhorizon.dev
    horizon-mixins Compile-time source mixins for Horizon, by levzzz5154 (MIT); the tool every native mod is built with
    horizon-native-mod-template The template these projects follow
    horizon-server A Minecraft Java 26.3 server written in Rust
    kira-pumpkin Kira, the Discord bot, answering in a Pumpkin server's chat
    .github The organisation profile

    Horizon's own native mods in horizon-mods/native/ are coords-hud, fps-overlay, keystrokes, minimap, zoom, recipes, smp and voicechat-server. This library adds independent mods beside them; none of them replaces those.
