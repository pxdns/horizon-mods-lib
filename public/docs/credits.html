    Credits

    Horizon

    • Horizon is made by Ludovic Marie and the Horizon contributors, MIT: horizon-rust/horizon.
    • horizon-mixins, the tool that turns these bundles into a game, is by levzzz5154, MIT: horizon-rust/horizon-mixins.
    • The structure of every project follows horizon-native-mod-template, itself based on levzzz5154's Veinminer port, MIT.
    • tools/mods.py is adapted from native/tools/native.py in horizon-rust/horizon-mods, MIT.
    • The site's look follows the Horizon website, horizon-rust/horizon-site, MIT: the same dark violet palette, card shapes and spacing, written again as plain CSS. No file from that site is copied.

    Tempest

    The ports and the module list come out of the Tempest client project, pxdns/patcher: its cross-pack matrix, its licence notes (docs/MOD-LICENSES.md) and its 1.16.5 port status.

    Icons

    • The nine projects' own icons (assets/icons/<project>.svg) are original artwork made for this library, MIT.
    • The catalogue's icons (assets/icons/catalogue/) are each upstream mod's own project icon, downloaded from Modrinth, shown only to identify the mod it belongs to. They are the work of those mods' authors (named on every catalogue page, from Modrinth's team listing) and are not covered by this repository's MIT licence: they stay under whatever terms the authors gave them. They are shrunk to 96 px and otherwise unaltered. Three projects have no icon on Modrinth and show a placeholder tile instead.
    • If you made one of these icons and want it gone, see DMCA and takedowns; it is removed without argument.

    The offline Horizon build

    horizon-offline.html (on the site's Play page) is a single-file offline build of Horizon, added by this repository's owner. Horizon is MIT, by Ludovic Marie and the Horizon contributors. The file's own comments name three projects it includes: xzwasm (an xz decoder), walloc (a WebAssembly allocator) and XZ Embedded; see their repositories for their terms. The file contains none of Minecraft's resources, and it is not an official release of the Horizon project as far as this repository can tell: it is unverified against Horizon's own releases.

    Fonts

    None are bundled. The site uses the visitor's own system fonts, so it loads no third-party font, script, analytics or tracker.
