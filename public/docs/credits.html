    Credits

    Horizon

    • Horizon is made by Ludovic Marie and the Horizon contributors, MIT: horizon-rust/horizon.
    • horizon-mixins, the tool that turns these bundles into a game, is by levzzz5154, MIT: horizon-rust/horizon-mixins.
    • The structure of every project follows horizon-native-mod-template, itself based on levzzz5154's Veinminer port, MIT.
    • tools/mods.py is adapted from native/tools/native.py in horizon-rust/horizon-mods, MIT.
    • The site's look follows the Horizon website, horizon-rust/horizon-site, MIT: the same dark violet palette, card shapes and spacing, written again as plain CSS. No file from that site is copied.

    The mods these are ported from

    Each project re-implements the behaviour of an existing mod. No code, art or text is copied from them, and they are not endorsed by their authors. The authors are credited here because the idea, the name and the design are theirs.

    Project Ported from Upstream licence
    fps-display FPS - Display (fpsdisplay) see the upstream project
    sprint-indicator Sprint Indicator (sprintindicator) see the upstream project
    key-overlay Key Overlay (KeyOverlay) see the upstream project
    cps-counter Tempest CPS module (own work) MIT
    info-hud MiniHUD (info lines) see the upstream project
    custom-hud CustomHUD (profile idea) MIT
    zoomify Zoomify (zoomify) see the upstream project
    simple-zoom Simple Zoom (simplezoom) see the upstream project
    waypoints Xaero's Minimap and World Map (waypoints idea) independent implementation, no upstream code

    The complete list of upstream projects with their authors' licences, as shown on Modrinth, is in the catalogue. A Modrinth page is the place to find who made a mod and to support them.

    Tempest

    The ports and the module list come out of the Tempest client project, pxdns/patcher: its cross-pack matrix, its licence notes (docs/MOD-LICENSES.md) and its 1.16.5 port status.

    Icons

    Every project's icon in this repository and on the site is original artwork made for this library (assets/icons/*.svg, MIT). No upstream mod's icon, logo or screenshot is bundled or hot-linked. Icons belong to their projects: the catalogue links to each upstream page instead of reproducing its art.

    Fonts

    None are bundled. The site uses the visitor's own system fonts, so it loads no third-party font, script, analytics or tracker.
