    Introduction

    horizon-mods-lib is a library of native mods for Horizon, the free, open-source rewrite of Minecraft: Java Edition 26.3 in Rust. Every mod is its own small project with its own tests, its own release and its own .hnmod file. They are ports: each one re-implements something people already use in Fabric (a FPS readout, a zoom, a key overlay, waypoints) on Horizon's native hook points.

    What a native mod is

    A Fabric mod is Java that gets loaded into the JVM. A Horizon native mod is Rust source that horizon-mixins merges into the game's own source before it is compiled. The launcher builds a game for the instance the mod is installed in, so the mod is not a plugin loaded at run time: it is part of the executable you play.

    That has consequences, and this library is built around them:

    • A mod can only do what the game's source lets it hook. Horizon keeps a short list of stable hook points (see Hook points); mods written against them build on any Horizon whose hook-point version is new enough.
    • A native mod runs with the player's rights, so the registry reads the source of every native mod before it lists it. These projects are small on purpose: a mod's logic is one runtime.rs file with unit tests, and each hook is a helper of a few lines.
    • Everything is MIT, nothing is minified, and the .hnmod contains exactly the .rs and .toml files you can read in the repository.
