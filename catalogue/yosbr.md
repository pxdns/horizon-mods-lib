# Your Options Shall Be Respected (YOSBR)

![Your Options Shall Be Respected (YOSBR) icon](../assets/icons/catalogue/yosbr.png)

**Status:** No 26.3 build - **Upstream licence:** `GNU Lesser General Public License v3.0 only` - **26.3 build:** `-` - [Modrinth](https://modrinth.com/mod/yosbr)

## Where it stands

Restores option files that the Java game resets; Horizon keeps its own options.

The upstream project has no build for Minecraft 26.3, the version Horizon implements. That does not stop a native port by itself; the reason it is not ported is on its page.
